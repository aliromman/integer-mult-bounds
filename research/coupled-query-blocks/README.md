# Coupled-query discovery archive

The complete proof and registered replay are public in PR6168, package
five-call-projector-rigidity. This directory retains the discovery script
and its aggregate 84-domain receipt. It also retains the three initial
all-full runs. Exact duplicate per-pattern receipts were removed after
comparison with the aggregate.

The free associative words retain their order. Matrix coefficients are not
assumed to commute. The 81 excluded site patterns and three surviving
alternating patterns agree with the registered proof. This archive is not
an independent review and does not claim a new kappa.
