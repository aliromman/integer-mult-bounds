# A caller with initialized work fields

This is a research contract, not a profitable construction. The selected frontier stays
unchanged. The source is still the forward P104 interface pinned in this
directory. Its native implementation and helper obligations remain.

Use n independent input fields and w additional owned fields, initialized
to zero. Let E embed the inputs in these n+w fields. Each full call has a
rank-two projector P and a compatible rank-one square-zero query N. It acts
as I-P+z P(I+S N), where S^2=1 and z commutes with all scalar field maps.
All scalar changes of field basis are explicit ordinary operations.

The proposed endpoint is rectangular:

    L F_l ... F_1 E = z^e S I_n,

where L is one constant ordinary matrix. The n displayed outputs must have
this identity on every input. Complete L to an invertible ordinary field
basis, install the first n outputs on the original fields, and clear the
other w owned fields. Their final values can depend on the input. They get
no productive target credit. Zero initialization is an explicit premise.
This contract differs from a square word that restores every field.

For n=4, w=2, l=4 and e=2, the initial search uses a formal stage variable.
The rank17 main targets would be possible with the retained advancing
stage if the full identity exists. Before all ordinary fees, the source
linear margin would be 4*104*17-4*1720=192. This is a counterfactual price,
not a proved supplier. The actual moment, native routes, owned allocation,
precision, compiler and BIT conditions must all be checked after an exact
word exists. No ordinary or recursive obligation is assigned zero cost.

This initial target is now excluded by MINIMAL-QUERY-DEGREE.md, for every
finite work-field count. The subsequent two-call degrees(2,1) target is
also excluded. The proof gives sum e_j<=n whenever l=n. The live test uses
five calls, four inputs and target degrees(2,2,3,3); the proof does not
decide that case. Its small size is a construction test, not a complete
profile that already beats the selected result.

The search will first use floating arithmetic and exact algebraic charts
for compatible projectors. A small residual must be reconstructed and
checked as a full polynomial identity. Failure of a bounded search does
not exclude the contract. A source field cannot be erased before its
required output is produced. Native helper inputs stay independent and
fresh at every full call, as in the source.

This scope concerns the outer caller. It does not take the changed native
decoder or helper-lifetime searches in Discussions5600 and5645, or the
G20 installation in5804. The signed and cyclic caller work remains in the
same canonical investigation, Discussion5593.
