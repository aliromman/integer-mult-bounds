# Caller research checkpoint

This is an active research draft. It establishes no new kappa. It is not a
registered replay package or a complete native caller.

The exact five-leaf binary word uses two thin maps of ranks5 and22. Its
complete scalar-polynomial replay passes, but its linear price loses716.
Normal and optimized runs agree. The known helper307 native construction
is a positive control from PR5601, not a new result.

The remaining files retain bounded searches over query frames, stage
projectors, native charts and coordinate permutations. A timeout means
unknown. A numerical residual is not an endpoint. See [LAB.md](LAB.md),
[WORK.md](WORK.md), [SOURCE-PINS.json](SOURCE-PINS.json) and
[CHECKPOINT-CHECKS.json](CHECKPOINT-CHECKS.json) for coverage and limits.

[ADVANCING-CONTRACT.md](ADVANCING-CONTRACT.md) proves a central-query
normalization and describes a changed advancing-stage contract. The exact
component check is `python3 -I -B involution_normalization.py` from this
directory. This component does not provide a profitable caller.

## Open next questions
