Python 3.12.13. The replayer does not run the certificate search. It checks
that each witness differs from one by explicit commutators, checks literal
2-by-2 and 3-by-3 matrix traces, and rejects a changed coefficient.

minor argument proves the general rank bound; the finite list does not
replace that argument. The source-authenticated rational price checks
passed for all nine short-word cases and both mixed-sign cases. Optimized
runs also passed. The separate SymPy parity controls include a genuine
one-full-call exception.

The selected source certificate is retained byte-for-byte and checked by
SHA256 and Git blob ID. The local paid and helper profiles are recounted.
The selected source word, native phase proof, full caller, compiler and outer
replay were not rerun. No new native implementation, selected-frontier
admission or kappa gain is claimed. Independent scientific review is pending.

The searches retain exact commands through their scripts and input fields.

These outcomes are not global impossibility results. The query-split search
is separate ongoing work and is not covered by the closure theorem.
