## Stage and query searches

The fixed canonical five-query tuple on four fields still fails the exact
second-coefficient equations, even with different compatible rank-two
projectors on the two J eigenspaces. discovery.py includes every rational
irreducible representation. Its two-field triangle passes all coefficients
and projector equations as a positive control.

The boundary-shear query search changes the query frames themselves. Four
numerical starts with 1,000 evaluations each have a nonzero residual. The
best norm is about .006458, with a largest parameter about20.754. This is
not an exact endpoint or a proof of impossibility.

[BOUNDARY-CHART.md](BOUNDARY-CHART.md) reduces the standard-representation
equations to a rational parameter chart. The explicit point
(2,3,4,5,15/8) passes that complete representation and fails the sign
representation. The sign equation forces a rank-two matrix. Its small
minors restrict the parameter sequence to at most three constant runs.
At n=4 all ten resulting run patterns fail or force the boundary shear
to be zero. This exact finite screen replaces the numerical attempt in
that chart. The generic four-variable Groebner computation timed out;
its timeout is not evidence for the exclusion.
